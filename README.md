# Gestor de Tareas

Un gestor de tareas por consola hecho con Python, guarda los datos en SQLite.

## Que hace

- Agrega tareas
- Deja ver todas las tareas
- Marcar una tarea como hecha
- Borrar una tarea
- ...

## Como funciona

```bash
python3 main.py
```

## Herramientas

- Python
- SQLite3
